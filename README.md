# payRoll2
このリポジトリは給与計算アプリケーションを、HTML・CSS・JavaScript を用いて Web ブラウザ上で動作するように実装したものです。

## 📌 概要

個別指導塾や教育関連のアルバイト向けに、以下の入力項目をもとに給与を計算できます：

- 授業コマ数
- プログラミングコマ数（プロクラ）
- 出勤日数（授業日）
- 事務作業時間（労働時間）

また、時給や手当などは人によって異なることがあるため、各単価はユーザーが自由に変更できるように設計されています。
